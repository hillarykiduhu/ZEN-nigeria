# ZEN-Nigeria working folder (Route A)

ZEN-garden 3.1.1 datasets for the MSc thesis, written directly in ZEN-garden format.
Reference year 2025, currency USD.

```
config.yaml                 points zen-garden at the active dataset
datasets/                   one folder per model stage (generated by scripts/build_slice.py)
scripts/build_slice.py      builds the stage-1 dataset; every PLACEHOLDER is marked in the script
scripts/plot_results.py     quick plots of a run
data_register/              parameter register, rice-husk cascade (live formulas), sources, decisions
data_raw/                   downloaded source files, one subfolder per source (keep originals untouched)
docs/                       data_plan.md and notes
templates/                  untouched 1_base_case from ZEN-garden 3.1.1 (format reference)
outputs/                    solver results (git-ignored)
```

## Commands (PowerShell, `conda activate zen-nigeria`, from this folder)
```
python scripts\build_slice.py templates\zen_garden_1_base_case_3.1.1 datasets
zen-garden --config config.yaml
python scripts\plot_results.py outputs\nigeria_stage1_rice_husk
zen-visualization
```

## Working rule for data
A number enters the model only after it has a row in the register with value, unit as published,
source, page or table, data year and price year. Until then it stays marked Placeholder.
The dataset is generated from `build_slice.py`, so change values there (the `P = dict(...)` block),
not by hand in the YAML files, then rebuild.
